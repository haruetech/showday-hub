# SHOWDAY 메인 페이지 (2026-10-25)

기존 Next.js 프로젝트 전체 파일입니다.

## 변경
- 새 축제·공연장 파노라마 배경 이미지 (텍스트가 포함된 시안 전체를 배경으로 쓰지 않고 장면만 잘라 사용)
- 음악제작의 모든 것 → 공연장 → 공연·여행지 찾기 → 여행 플랜 → 로컬 라이프 순서
- 상단 5개 메뉴와 서비스 카드 제목: 마우스를 올리거나 키보드 포커스 시 한글 → 영어
- K-RICE CAKE 등 천막 문구는 이미지에 포함된 시안의 일부입니다. 실제 HTML 텍스트가 아니므로 개별 수정은 이미지 교체가 필요합니다.
- 공연장 예매 기능은 표시하지 않습니다.
- 5개 서비스 카드 및 바로가기: 새 탭 이동
- 서비스 소개/영상 팝업 기존 유지 (영상 업로드 전 준비 중 표시)
